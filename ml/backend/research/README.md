# Historical research

These experiment records and evaluation tools are retained as evidence for the
project's reported results. They are not imported by the app or included in the
cloud upload bundle. They mention models/providers that are no longer active.
Some scripts contain the former directory layout: review paths and recreate any
required evaluation environment before rerunning. Do not interpret historical
successful experiments as currently supported app features.

Downloaded CatVTON weights/source and disposable browser profiles were removed.
The public aggregate results remain in `../docs/evaluation-assets` and earlier
reports in `../docs/history`. Local benchmark datasets remain under storage for
reproducibility and must not be published with user photographs.
