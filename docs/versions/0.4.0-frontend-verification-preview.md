# Version 0.4.0 — Frontend preview

Intended Git tag: v0.4.0-frontend-verification-preview. Date: November 5, 2026.
This is a source checkpoint for backend integration preparation, not a signed Android release or a claim of complete device validation.

## Changes
- All planned frontend areas are represented in the workflow navigator.
- Non-password editor drafts, selected photos and outfit selections survive screen navigation in session memory.
- Draft keys isolate preview and account data. Login, sign-out and expiry clear draft memory. No draft database or browser localStorage is used.
- Changed active drafts trigger a browser unload warning while their screen is mounted. Browser restart/app restart clears drafts.
- Explicit discard remains confirmed. Successful editor saves clear the relevant draft.
- Field hints include validation feedback; text input lengths are bounded; shared chips and links have 48px minimum targets.
- TypeScript source formatted consistently.
- CI verifies types, lint, tests and Android JS export; successful runs retain an export artifact for 30 days.

## Verification scope
Local typecheck, lint, tests and Android export are required before tagging. See checkpoint 003 for actual results.
