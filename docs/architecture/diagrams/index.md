# Drape & Drop diagrams

These 15 diagrams were supplied in the `DrapeandDropRequirements` folder and are preserved without image edits. Filenames and directories were standardized for repository navigation. See the [source inventory and checksums](inventory.md).

These are requirements/design illustrations, not evidence of deployed functionality. ML inference, compatibility scoring and conversational AI remain deferred. Payment-dispute and notification flows are supplied design references; importing them does not add those features to the application. Refer to the [implementation tracker](../../workflows/SADD_IMPLEMENTATION_TRACKER.md) for actual status.
