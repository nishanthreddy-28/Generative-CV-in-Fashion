# FashionAI – Virtual Try-On System (PRD)

## Problem
Users cannot visualize how clothes will look on them while shopping online.

## Solution
An AI-powered fashion system that:
- analyzes clothing images
- generates outfit suggestions
- provides virtual try-on using pretrained models

## Users
- College students
- Online shoppers
- Fashion content creators

## Core Features (MVP)
1. Upload wardrobe images
2. AI clothing detection (pretrained models only)
3. Outfit generation using LLM
4. Virtual try-on using API/model
5. Save outfits

## Tech Stack
- Frontend: Next.js
- Backend: Node.js / API routes
- DB: Supabase
- Storage: Supabase
- AI: OpenAI / pretrained CV models

## Goal
Convert ML research into a production-ready AI fashion product.
